# Change Log

## [0.1.0] - 2026-06-29

### Added
- Added Explorer file decorations for compact file size badges.
- Added a `otakFilemeter.badgeMetric` setting to switch badges from file size to line count.
- Added optional line counts in file size tooltips.
- Added bounded line counting with binary-file detection and a configurable maximum file size.
- Added localized package metadata for English and Japanese.
